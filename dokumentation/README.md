# Documentation

This catalogue contains documentation of the 3CIM ver 2.0 

- 3CIM ver2.0_Beskrivning.pdf 
Description of the 3CIM model and its relation to CityGML. (in Swedish)

- Användarguide_3CIM_version_1.pdf
User guide how to use the 3CIM model, including the 3DCityDB database environment. (in Swedish)

- 3CIM_v1.0.pdf. A journal paper that provides background of 3CIM.

- Olsson_et_al_2025_representation...pdf. A journal paper that describes 3CIM ver 2.0 with focus of land cover representation.

- Instruktioner UML modellering och ShapeChange.pdf. Instructions of UML modeling for the 3CIM model. (in Swedish)

The catalogue also have some files that describes specific parameter settings in programs linked to 3CIM data.
